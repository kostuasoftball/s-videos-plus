# Происхождение кода

Адаптеры, `adapter-utils.js` и `auth.js` перенесены из собственного проекта пользователя
`kostuasoftball/sisiplus-lampa`, ветка `codex/beta-1.0.3-stripchat-regions`,
коммит `70784f78c6ba3aa02a52e2f864790b9d41598131`, с разрешения владельца.
Перенос выполнялся копированием; исходные файлы и репозиторий плагина не изменялись.
Первоначальная заметка исследования адаптеров: `SisiPlus/THIRD_PARTY.md` в том проекте.

Lampa используется как архитектурный ориентир. Код приложения Lampa в этот проект не включён.
Android UI, мост, сетевой транспорт, управление каталогом и сборочная конфигурация написаны
для S Videos + отдельно. AndroidX Media3 — Apache License 2.0; подключается через Maven.
Playwright применяется только для локальных тестов — Apache License 2.0.

Публичный прокси Cherry — внешняя необязательная зависимость. Его код не включён,
доступность не гарантирована; пользователь должен явно включить резервный транспорт.
