# Проверка первой alpha — 9 ноября 2026

## Выполнено локально

- 6 автоматических тестов: синтаксис и регистрация 8 адаптеров без Lampa; защита от
  запоздавших ответов; фильтры и пагинация; запрет отправки Cookie в публичный прокси;
  мост Android; восстановление после ошибки каталога.
- Headless Chromium: 4 карточки в строке; D-pad вверх/вниз; фильтр на правом краю;
  плоский список стран с 6 заголовками; поиск и Back; настройки Cookie; смена источника.
  JavaScript runtime errors не обнаружены. Превью при этих тестах — явно помеченное демо.
- Исходный репозиторий плагина не изменён. Приложение создано в отдельной папке и Git-репозитории.

Это проверка каталогов с ПК, не доказательство воспроизведения на ТВ. Сетевой стек Android,

недоступный источник показывает ошибку/пустой результат, а не подменяется демо.

Отдельно у Stripchat разрешены качества `original`, `480p`, `240p`; запрос HLS-манифеста
вернул HTTP 200 и корректный заголовок `#EXTM3U`. Декодирование видео на конкретном ТВ
этой сетевой проверкой не подтверждается.

## Android

GitHub Actions выполняет `assembleRelease`, `lintRelease` и `apksigner verify`.
Первый успешный build: коммит `08c4c4b`.
Публикация тега дополнительно требует успешного smoke-теста установки и запуска release APK
на эмуляторе API 30, отрисовки локального WebView, offline-ошибки и Back/подтверждения выхода.
Скриншот эмулятора сохраняется как артефакт сборки. Этот тест не проверяет декодирование
реальных потоков и не заменяет проверку физического Android TV.

Успешный выпуск: `v0.1.0-alpha.3`, коммит приложения `b6bf0f2`.
[Android build + emulator smoke](https://github.com/kostuasoftball/s-videos-plus/actions/runs/42579262090):
сборка release, Lint, проверка подписи, установка на API 30, готовность WebView с восемью
источниками, Back/подтверждение выхода и отсутствие AndroidRuntime crash — успешно.
Ранние теги alpha.1/alpha.2 не публиковали APK, поскольку проверки обнаружили проблему
совместимости старого WebView. В alpha.3 устранены `replaceChildren`, расчёт масштаба
и зависимость геометрии от новых CSS-свойств.

Реальные Cookie аккаунтов не использовались и не включены ни в исходники, ни в APK.
