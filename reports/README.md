Перед сборкой alpha.4 повторно проверены загрузка превью и начальных данных
HLS (медиасегмента либо fMP4 initialization segment): Stripchat, XVideos,

Диагностика сначала повторно запрашивала корневой плейлист Chaturbate, что
давало 403; после переиспользования первого ответа, как делает плеер,
вложенные плейлисты и начальные данные загрузились. Исторический первичный
протокол сохранён без подмены результата.

проксированный xvideos2.com; крошечная страница .com не принята за каталог.

сторонние редиректы и заглушки других адресов исключены из рабочего списка.

тогда как ukr/ee дают 403. У Runetki рабочий каталог/превью/HLS получены через
runetki12.com; остальные проверенные адреса дают 403 или обрыв соединения.
Для Stripchat основной публичный каталог уже использует отдельный API:
открытие главной страницы зеркала не доказывает работу этого API.

## Локальные исправления

- Настройки → Зеркала: выбор предпочтительного адреса отдельно для Pornhub,
  XVideos, Xhamster, Chaturbate, BongaCams и Runetki; выбор сохраняется между
  запусками. «Автоматически» возвращает обычный перебор. При ошибке вручную
  выбранного адреса остаётся резервный перебор остальных известных адресов.
  Stripchat использует отдельный API; неподдерживаемая замена домена для него
  не предлагается. eFukt не включён в этот раздел.
- Автоматический перебор явно разрешённых публичных зеркал, запоминание
  успешного адреса и проверка структуры каталога, а не одного HTTP-статуса.
- Ограниченные таймауты запросов и общий срок перебора адресов.
- Cookies/Authorization никогда не переносятся на зеркала или публичный прокси.
- Принудительный прокси применяется к превью/потокам; API сохраняет возможность
  прямого доступа к рабочим зеркалам.
- Сохранены отдельные качества HLS Pornhub: раньше все перезаписывали ключ HLS.
- Добавлены регрессионные тесты выбора зеркала, защиты сессии и качеств видео.

Pornhub пока нельзя считать стабильно исправленным: каталог и превью доступны,
но часть публичных подписанных HLS-ссылок отвечает 410 даже через резерв.
Истечение срока ссылки не установлено: в отдельной диагностике срок ещё не истёк.
