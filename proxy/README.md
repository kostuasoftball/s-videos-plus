# Собственный HTTPS-прокси

Это исходник необязательного Cloudflare Worker, а не уже развёрнутый сервис.
Встроенный резерв приложения использует Cherry. Собственный сервер нужен, если
публичный сервис заблокирован источником или недоступен в вашей сети.

1. Создайте Worker в своём Cloudflare-аккаунте и вставьте `worker.mjs` как модуль.
2. В настройках Worker добавьте **secret** `PROXY_KEY` со случайным длинным ключом.
3. Разверните Worker. Без ключа он намеренно возвращает 503, без корректного ключа — 403.
4. В S Videos + → Настройки → Сеть и прокси → Свой HTTPS-прокси укажите:

```text
https://YOUR-WORKER.YOUR-ACCOUNT.workers.dev/?key=YOUR-KEY&url={url}&referer={referer}
```

5. Сохраните адрес и включите принудительный режим для проверки.

Worker передаёт бинарные изображения/видеосегменты как поток, сохраняет Range/206,
передаёт Referer/Origin для CDN. Он не пересылает Cookie и Authorization пользователя.
HLS-сегменты, вложенные плейлисты и ключи маршрутизирует нативный плеер приложения;
манифесты не переписываются и не кэшируются. Это важно для живых трансляций.

Прокси не гарантирует обход anti-bot/CAPTCHA или IP-ограничений площадки. Cloudflare
может ограничивать такую нагрузку по своему тарифу и условиям; этот проект не создаёт
аккаунт, не подключает платный тариф и не развёртывает Worker автоматически.
