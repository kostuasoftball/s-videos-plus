# Установка S Videos + на Android TV

## Обновления из приложения (начиная с alpha.4)

Откройте Настройки → Проверить обновления → Обновить. Приложение скачает APK
из GitHub Releases и проверит размер, SHA-256, пакет, номер версии и подпись.
Если Android запросит разрешение «Установка неизвестных приложений», разрешите
его для S Videos + и вернитесь назад: установка продолжится. В системном
установщике подтвердите обновление. Полностью тихая установка без root/управления
устройством невозможна. Скачивание может не работать в сети, блокирующей GitHub.
Настройки сохраняются при установке поверх версии с той же подписью; удалять
предыдущую версию не нужно. Alpha.3 сначала обновляется вручную до alpha.4.

## Первая установка

В alpha.7: первое «Назад» в плеере скрывает весь HUD (включая верхнюю строку), следующее «Назад» при скрытом HUD закрывает видео. OK возвращает HUD, не запускает кнопку под фокусом и не ставит видео на паузу. После выхода фокус восстанавливается на последнем воспроизводившемся ролике; влево от первого столбца — текущий источник, вправо из источников — последняя карточка. Добавлены короткие анимации 150 мс (прозрачность/сдвиг) и переходы цвета 120 мс, без изменения геометрии. Учитывается prefers-reduced-motion. Работоспособность источников в этом выпуске не исправлялась и не проверялась на реальном ТВ.

В alpha.7 запуск приложения не выбирает и не загружает источник автоматически: фокус на первом видимом источнике, карточки появляются только после OK/клика. Также добавлено «Настройки → Источники»: показывать/скрывать существующие источники. Выбор видимости сохраняется между запусками; при скрытии текущего выбранного источника выбирается видимый. На стартовом экране изменение видимости не запускает каталог. Последний источник скрыть нельзя. Ручное добавление сервисов не реализуется по просьбе пользователя.

Начиная с alpha.6: в меню стран удерживайте Enter/центральную кнопку или левую кнопку мыши около 650 мс. Появятся действия «Переместить», «Закрепить наверху»/«Открепить», «Скрыть». Перемещение — внутри текущего раздела; закреплённые страны располагаются после «Все страны». Вернуть скрытые пункты можно через «Показать / скрыть страны». Порядок и видимость сохраняются отдельно для каждого источника; скрытие пункта не исключает видео из каталога. Удержание проверено автоматически в браузере, не на физическом ТВ.

Начиная с alpha.5: Настройки → Аккаунт → Ввести Cookie с клавиатуры ТВ / Google TV.
Выберите поле на ТВ, откройте клавиатуру пульта в Google TV на сопряжённом
смартфоне, вставьте строку и нажмите «Сохранить». На ТВ используется обычный
Android EditText без автокоррекции. Поле открывается пустым; отмена не меняет
сохранённую сессию. Черновик очищается при закрытии. Текст виден на ТВ:
не показывайте его посторонним. Прямое копирование из буфера смартфона
зависит от версии Google TV и системной клавиатуры; приложение не имеет
доступа к буферу другого устройства. Проверка с физическим смартфоном нужна.

1. Откройте Releases: https://github.com/kostuasoftball/s-videos-plus/releases
2. Скачайте `S-Videos-Plus.apk` из последнего опубликованного выпуска.
3. Перенесите APK на телевизор (USB, локальная передача файлов или браузер/Downloader).
4. Разрешите установку приложений из этого источника в системных настройках Android TV.
5. Установите APK. Откройте **S Videos +** в списке приложений телевизора.

Это самостоятельное приложение: добавлять ссылку в Lampa не нужно. Компьютер после
установки может быть выключен. Для реальных каталогов и потоков нужен интернет.

Управление: стрелки — фокус; OK — выбор; удержание OK на карточке — меню видео;
Back — закрытие панели/плеера, затем подтверждение выхода из приложения.

Аккаунты Stripchat/Chaturbate необязательны. Для переноса сессии откройте Настройки →
Аккаунт соответствующего сайта → вставьте Cookie → Сохранить → Проверить подключение.
В alpha.4 при проблемах с картинками/потоками откройте Настройки → Сеть и прокси →
Принудительно через прокси. Резервный маршрут применяется к публичным страницам,
превью, HLS-плейлистам, сегментам и ключам; Cookie-сессии сторонним сервисам не отправляются.
Если Cherry также заблокирован источником, можно указать собственный HTTPS-прокси.

При ошибке конкретного сайта попробуйте другой источник, другую сеть или резервный
прокси. Сообщите номер версии, источник, действие и текст ошибки. Настоящие Cookie
в скриншотах/issue публиковать не нужно.
