# Установка S Videos + на Android TV

1. Откройте Releases: https://github.com/kostuasoftball/s-videos-plus/releases
2. Скачайте `S-Videos-Plus.apk` из последнего опубликованного выпуска.
3. Перенесите APK на телевизор (USB, локальная передача файлов или браузер/Downloader).
4. Разрешите установку приложений из этого источника в системных настройках Android TV.
5. Установите APK. Откройте **S Videos +** в списке приложений телевизора.

Это самостоятельное приложение: добавлять ссылку в Lampa не нужно. Компьютер после
установки может быть выключен. Для реальных каталогов и потоков нужен интернет.

Управление: стрелки — фокус; OK — выбор; удержание OK на карточке — меню видео;
Back — закрытие панели/плеера, затем подтверждение выхода из приложения.

Аккаунты Stripchat/Chaturbate необязательны. Для переноса сессии откройте Настройки →
Аккаунт соответствующего сайта → вставьте Cookie → Сохранить → Проверить подключение.
Отключённый по умолчанию резервный прокси включается в Настройках; он применяется
только к публичным страницам и не используется для Cookie-сессий.

При ошибке конкретного сайта попробуйте другой источник, другую сеть или резервный
прокси. Сообщите номер версии, источник, действие и текст ошибки. Настоящие Cookie
в скриншотах/issue публиковать не нужно.
